MODE D'EMPLOI

Clique un joueur encadré et choisis son nom. Le nom se propage aux autres images du même joueur (pointillé = proposé) : corrige seulement ce qui est faux.
Joueur oublié : trace un cadre autour de lui en glissant la souris.
Faux positif (public, reflet, poteau…) : survole le cadre et appuie sur X (ou « ✕ Pas un joueur ») : il est écarté sur toutes les images de la même piste.
Un nom passe sur un autre joueur à partir d'une image (la piste a changé de joueur) : sur la première image fausse, survole le cadre, appuie sur C (✂ couper) puis donne le bon nom. Les images d'avant gardent l'ancien nom. C à nouveau annule la coupure.
